Before you install

The installer is unsigned, so Windows may show an unknown-publisher warning. Only install a copy you trust. Folio uses Microsoft Edge WebView2; setup may need internet if that runtime is missing.

Optional GitHub backup requires your own private repository and token. Ordinary note-taking does not require an account.

A FEW SMALL DETAILS

Good to know.

Does Folio replace my notebook?

No. Keep your everyday thinking on paper. Folio holds the examples, explanations, and references you want to attach to a handwritten page.

Where are my notes stored?

In a local SQLite database on your computer. Export JSON backups to keep an independent copy. Optional GitHub backup sends a copy to a private repository you configure.

Can I use it without internet?

Yes. Once installed with its required runtime, normal note-taking, searching, and local import/export work offline. Remote backup needs a connection.

Does it sync with my phone?

This version is for Windows. GitHub backup is for recovery; it is not automatic two-way device synchronization.
